Glow Box 비공식 한국어 패치 v1.0.0

사용 방법
1. Glow Box를 종료합니다.
2. GlowBox_Korean_Patch_v1.0.0.exe를 실행합니다.
3. 설치 폴더를 확인하고 [한국어 패치 설치]를 누릅니다.
4. 게임을 실행하고 언어에서 한국어를 선택합니다.

패치를 제거하려면 같은 EXE를 실행하고 [원본 복구]를 누릅니다.

주의
- Steam 게임 파일 무결성 검사를 실행하면 한국어 패치가 제거될 수 있습니다.
- 게임 업데이트 후에는 새 버전 대응 여부를 확인하세요.
- 원본 파일은 게임 폴더의 KoreanPatch_Backup에 자동 보관됩니다.
